3. Describe how a browser requests and displays a web page from a web server.

Ans-When I enter a website address, the browser sends a request to the web server. The server sends the website files back to the browser. The browser reads these files and shows the web page. This process happens in a few seconds.

4. Identify and list the tools required to set up a web development environment. Explain the purpose of each.
Ans-VS Code – Used to write code.
Web Browser – Used to see the website.
Node.js – Helps run JavaScript.
Git – Used to save and manage code.

5. Explain what a web server is and give examples of commonly used servers.

Ans-A web server stores website files and sends them to the browser when someone opens a website. It helps users access web pages on the internet. Some common web servers are Apache, Nginx, IIS, and LiteSpeed.

6. Define the roles of a frontend developer, backend developer, and database administrator in a project.

Ans-A frontend developer makes the design of the website. A backend developer writes the code that makes the website work. A database administrator stores and manages the website data. All of them work together to build a website.

8. Explain the difference between static and dynamic websites. Provide an example of each.

Ans-A static website shows the same content to every user. A dynamic website changes its content based on the user or data. A portfolio website is a static website. Facebook is a dynamic website.

9. Research and list five web browsers. Explain how rendering engines differ between them.

Ans-Five web browsers are Google Chrome, Mozilla Firefox, Microsoft Edge, Safari, and Opera. A rendering engine is used to display web pages. Chrome, Edge, and Opera use Blink. Firefox uses Gecko, and Safari uses WebKit.
